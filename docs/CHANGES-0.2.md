# MIRA 0.2 — изменения для просмотра

Пользователь хотел общаться с MIRA в чате. В 0.1 каждый вопрос заменял предыдущий ответ, история не передавалась модели, а запрос создать образ из вещей мог вызвать «Образ уже удалён».

Теперь MIRA показывает переписку, сохраняет её в документе аккаунта и передаёт предыдущие сообщения при уточнении. Ответ может содержать только текст или карточки подтверждаемых действий. Запрос «Что надеть завтра?» может привести к уточнению повода и подбору нового образа из реальных вещей. Сохранение образа и его плана выполняется вместе. Перенос существующей встречи показывает старое и новое время.

## Изменения

- Новый интерфейс чата: сообщения, закреплённое поле ввода, отправка, начальные подсказки, повтор запроса, очистка истории.
- Последние 60 сообщений сохраняются локально и синхронизируются в облако; последние 16 передаются при очередном запросе. История изолирована по аккаунтам.
- Действия: задача, существующий образ, новый образ из вещей, питание, перенос существующего события. Каждое требует подтверждения. Дубликат одного предложения блокируется сохранённой отметкой.
- Сервер проверяет роли и размеры истории, календарные даты, типы источников и включённые разделы; вымышленные ссылки не превращаются в исполнимые карточки.
- Прогноз на 7 дней по выбранному городу с явными датами.
- Понятные сообщения о таймауте, авторизации, CORS, лимите и недоступности провайдера.
- Исправлены независимое копирование документа, очередь разрешения конфликта, поздний ответ при смене аккаунта, смена аккаунта во время выбора фото и вызов setState после закрытия регистрации.
- Версия приложения 0.2.0+2. Обновлены инструкции, QA и серверные проверки CI.

## Проверка

26 Flutter-тестов и 5 серверных тестов пройдены. Анализ без замечаний. Web release собран. Детали и непроверенные интеграции: [VALIDATION.md](VALIDATION.md).

Изображение [chat-preview.png](chat-preview.png) — рендер нового интерфейса с явно заданным тестовым диалогом, не реальный ответ OpenAI.

## Установка

Изменения пока только локальные. Развёртывание новой `mira-ai` и установка нового клиента должны быть согласованными; SQL-миграция не требуется. Порядок обновления: [SETUP.md](SETUP.md#обновление-существующей-установки-до-02).
