## Scope

7,793 complete-nutrition foods from USDA FoodData Central SR Legacy (April 2018 export), with the original 62 Russian display labels preserved and Russian category/search keys added to additional entries. Other descriptions remain in English to avoid claiming unreviewed exact translations. This is historical USDA SR Legacy data, not comprehensive or current coverage of Russian packaged products. It works offline and requires no API key. The draft also implements manual barcode lookup; broad branded text search is still pending.

Values are source data, not generated by AI. Energy is nutrient 1008 (KCAL); protein, fat, carbohydrate are 1003, 1004, 1005 (G), per 100 g edible portion. Incomplete records are omitted; missing values in the original 62 curated records fail the importer. Missing values never become zero. The catalogue distinguishes preparation states and relevant fat content. Generic averages need not equal a specific manufacturer's label. Carbohydrate definitions vary across nutrition standards; this catalogue preserves USDA's source value without recomputing energy from macros.

Source: https://fdc.nal.usda.gov/download-datasets/

The JSON stores the archive SHA256, release, original English descriptions, FDC IDs and publication dates. Russian labels are Mira's translations, not official USDA labels. Do not imply that cottage cheese is interchangeable with all Russian tvorog, or that dry/cooked weights are interchangeable.

## Reproduce

Download the named USDA archive, then run:

```sh
python scripts/import_usda_catalog.py /path/to/FoodData_Central_sr_legacy_food_csv_2018-04.zip
```

The importer checks IDs, nutrient units, completeness and duplicate nutrient records. Review every label against its exact English description before expanding the curated list. An update must not silently refresh historical food/meal snapshots.

## Behaviour

- Search accepts Russian and original English names, case differences and е/ё. Common aliases return multiple choices; no automatic name-only matching.
- Selection shows values and the source release before confirmation.
- Import only follows the explicit selection. Identical previously imported records are reused. Changed local records are not overwritten.
- Recipe selections remain staged until recipe save. Food imports and recipe creation commit together through the existing atomic local document mutation; cancellation or failed validation writes nothing.
- Imported food source metadata survives ingredient/meal snapshots and account document serialization. Editing nutrient values flags the local copy as user-edited.
- Existing AI already receives saved food records. Once an ingredient is imported, AI can reference its actual food ID. This feature does not guess missing ingredient matches or use model-generated nutrition numbers.
