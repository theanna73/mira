# Mira 0.3 — согласованное визуальное направление

Изменения подготовлены относительно 88121008 (дерево совпадает с merge-коммитом main 83f62ff4). 03/10/2026 Анна одобрила показанное визуальное направление и разрешила отправку изменений в отдельную ветку GitHub с pull request. Слияние и публикация приложения не разрешены.

## Реализовано

- Шесть шагов знакомства и кнопка входа на первом экране при настроенном Supabase. Сохранённый профиль с onboarded пропускает знакомство; при загрузке облачного профиля показывается ожидание.
- Светлая палитра, MIRA и заголовки Cormorant Garamond (OFL), бирюзовые элементы, фотография приветствия. Горизонтальные фильтры, сетка собственных вещей, сводка калорий и БЖУ. Полосы БЖУ отображаются только при заданных пользователем целях.
- Даты интерфейса дд/мм и дд/мм/гггг; время чч:мм. Хранение и API сохраняют ISO.
- Запасы: отдельные упаковки продуктов, лекарств, косметики и ухода; место, количество, срок, открытие и период после открытия. Выбирается более ранний срок, месяцы учитывают последний день месяца. Можно отметить израсходованное. notifyDays определяет появление в «Сегодня», а не push-уведомление.
- Списки с пунктами, выполнением и закреплением. Удаление списка удаляет его пункты.
- «Последний раз»: дата выполнения, период повторения, отметка сегодня.
- Порядок и видимость блоков «Сегодня» сохраняются в профиле.
- create_recipe из чата сохраняет ингредиенты и инструкции и, при указанной дате, план питания одним изменением. Требуется подтверждение карточки. История сохраняет состав предложения. Известные БЖУ рассчитываются по реальным продуктам; при неизвестных данных рецепт не учитывается как нулевые калории.
- Сервер передаёт AI только разрешённые поля и продуктовые запасы; записи лекарств/косметики не включены в контекст питания.

- Flutter analyze: без замечаний.
- Flutter test: 34 теста пройдены. Проверены сохранение форм на размере телефона, пропуск знакомства, создание и выполнение пункта списка, срок после открытия и конец месяца, атомарность рецепта, связи и расчёты питания, история/подтверждение чата и существующие сценарии.
- Deno: 6 тестов пройдены; mira-ai и delete-account проходят type check.
- Web release: сборка выполнена (JavaScript; Wasm dry run тоже прошёл).
- docs/visual-review-0.3: реальные рендеры Flutter 390×844, масштаб 2, демонстрационные данные. Ответ чата подставлен для воспроизводимого просмотра, запрос к OpenAI не выполнялся. Кнопка входа в этих рендерах неактивна, потому что тест не подключён к Supabase.
