Flutter проверялся на версии 3.35.7. Deno — 2.5.4. Серверные зависимости при проверке типов установлены локально через npm; deployment использует npm-импорт Supabase SDK.

Обычная финальная web-сборка в этой среде столкнулась с `IconTreeShakerException` в оптимизаторе Flutter. Сохранение полных шрифтов иконок через `--no-tree-shake-icons` устранило сбой. Этот параметр включён в команду CI и инструкцию запуска. Приложение не зависит от tree shaking для правильной работы.

Тесты проверяют БЖУ рецептов и снимки истории питания, ссылки гардероба и историю носок, проверку AI-действий, отказ при ошибке сохранения, работу без сети, конфликт двух устройств, изоляцию аккаунтов, повторное нажатие «Съедено», открытие локальных данных без ожидания облака, онбординг и заполнение форм на экране шириной 390 пикселей.
